# Komentář k zákonu č. 87/1995 Sb., o spořitelních a úvěrních družstvech

Otevřený komentář k zákonu o spořitelních a úvěrních družstvech — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; družstevní záložna a její povolení, členství a členský vklad, orgány a vhodnost jejich členů, řídicí a kontrolní systém, kapitálové rezervy, pojištění vkladů, dohled ČNB, přestupky a opatření k nápravě.

Konsolidované znění: dokument e-Sbírky `SB-1995-00087_2026-01-11`.
